# pizza-calculator

A simple pizza ingredient calculator built with React.

## Features
- Calculate the amount of ingredients needed based on the number of pizzas.
- Calculate the amount of yeast needed based on the dough type and fermentation time and temperature.
- Responsive design for use on both desktop and mobile devices.
- User-friendly interface.
- Dark mode support.
- Localization support for multiple languages.
- Unit conversion between metric and imperial systems.

## Usage
To run the side locally, follow these steps:
1. Clone the repository:
   ```bash
   git clone
    ````
2. Navigate to the project directory:
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser to the side provided in the terminal (usually `http://localhost:3000`).
